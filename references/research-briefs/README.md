# Legacy Location (Moved)

Research brief files no longer live in `references/research-briefs/`.

Use venue-local notes folders instead:
- `venue/<venue-name>/shows/notes/<song-slug>.json`
- `venue/<venue-name>/shows/notes/<song-slug>.md`

For home studio, use:
- `venue/home-studio/shows/notes/`

Helper scripts in this folder remain as wrappers.
Pass `--venue` when multiple venues exist.
