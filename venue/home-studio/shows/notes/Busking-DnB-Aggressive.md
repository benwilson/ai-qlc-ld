# Busking: DnB + Aggressive Mood

## Details

- **Venue**: Home Studio
- **Genre**: Drum & Bass
- **Mood**: Aggressive
- **BPM**: 174
- **Generator**: `venue/home-studio/generators/Busking-DnB-Aggressive.py`

## Color Palette

Aggressive mood filters DnB palette to hot, high-contrast pairs. Blues and teals dropped as primary pars; only appear in complementary opposition to reds.

| Combo | Movers | Pars | Vibe |
|-------|--------|------|------|
| Classic DnB | Red | Blue | Complementary tension, signature DnB |
| Blood Moon | Red / Amber | Amber / Red | All-hot, pure aggression |
| Whiteout | White | Red | Maximum impact, clean + violent |
| Fire & Ice | Red | Cyan | Complementary contrast, aggressive heat |
| ALL WHITE | White all | White all | Full blast reset |
| ALL RED | Red all | Red all | Monochrome assault |

## Position Presets

All 9 area positions (C, DSC, USC, SL, SR, DSL, DSR, USL, USR) plus DJ Booth, Dance Floor, and Ceiling. Positions are solo-framed — one active at a time.

## Movement Chasers

All movement timing is 2x speed (aggressive mood CHASE_MULT=0.5):

| Chaser | Path | Run Order | Character |
|--------|------|-----------|-----------|
| LR SWEEP | Far L → SL → C → SR → Far R | PingPong | Wide aggressive sweep |
| RL SWEEP | Far R → SR → C → SL → Far L | PingPong | Reverse wide sweep |
| NARROW LR | SL → C → SR | PingPong | Tight, fast center sweep |
| CROSS | USL → DSR → USR → DSL | Loop | X-pattern, high energy |
| FRONT-BACK | DSC → C → USC | PingPong | Push/pull audience ↔ DJ |
| BEAT SNAP | SL → C → SR → C | Loop | Instant snap per beat, angular |

## Strobes

All strobes are Flash (momentary) action — hold to strobe, release to stop.

- STROBE ALL: Every fixture fast strobe
- STROBE MOVERS: Sharpy + BSW + Profile only
- STROBE PARS: 4BAR + Missyees + NI3K only
- FLASH WHITE: Full white bump (no strobe, just intensity)

## Specials

- BLACKOUT: All zero (Toggle)
- WHITEOUT: Full white + fast strobe + lasers (Flash)
- HOME: Center, red, full intensity — the "reset" button
- LASERS ON/OFF/STROBE: NI3K laser control (lasers-only mode, LEDs killed)
- PRISM CHAOS: All movers dual prism + gobo (Toggle)
- GOBO TEXTURE: Gobo only, no prism (Toggle)
- OPEN BEAM: Clear all movers of gobo/prism/frost (Toggle)
- NI3K SPIN: Fast head rotation (Toggle)

## Mood Buttons

Three intensity levels of the aggressive mood as pre-built looks:

- AGGR LOW: Sharpy only, red, dim — tension before the hit
- AGGR MID: Sharpy + BSW + 4BAR + NI3K, red, high intensity
- AGGR HIGH: Full rig, prism chaos, gobos, lasers, NI3K spinning — maximum violence

## Intensity Sliders

- MOVERS: Controls Sharpy + BSW + Profile dimmers
- PARS: Controls 4BAR master + both Missyee masters
- NI3K: Controls NI3K dimmer

## Usage Tips

1. Start with AGGR LOW or HOME for your base state
2. Colors are solo-framed — tap to switch palettes instantly
3. Positions are solo-framed — movement chasers override position buttons
4. Hit BLACKOUT for 1-2 beats before a drop, then WHITEOUT or AGGR HIGH
5. Strobe buttons are momentary — hold during drops, release for clean beats
6. PRISM CHAOS + BEAT SNAP + STROBE MOVERS = peak drop energy
7. Kill with OPEN BEAM to return to clean looks after chaos
8. Aggressive mood means: never let anything sit still for more than 2 bars
